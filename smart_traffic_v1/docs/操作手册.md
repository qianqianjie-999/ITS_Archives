# 智能交通建设档案系统 — 操作手册

---

## 1. 系统概述

智能交通建设档案系统是一套用于管理智能交通前端设备（信号灯、电子警察、违停球、卡口、结构化相机）、后端设备、项目信息、质保状态及电子档案的综合管理平台。

### 1.1 主要功能模块

| 模块 | 说明 |
|------|------|
| 首页仪表盘 | 设备统计概览、质保到期提醒 |
| 项目管理 | 项目信息、验收日期、质保期限管理 |
| 路口管理 | 信号灯、电子警察设备配置与质保管理 |
| 点位管理 | 违停抓拍、卡口设备、结构化相机配置与质保管理 |
| 后端设备 | 服务器、存储、交换机等后端设备管理 |
| 数据统计 | 设备数量统计与 Excel 导出 |
| 服务排名 | 设备服役年限排名，按年限排序展示全部设备 |
| 附件管理 | 电子档案上传、下载与关联 |
| 备忘录 | 工作记录与备忘 |
| 用户管理 | 账户管理与角色权限控制（管理员专属） |

### 1.2 角色与权限

| 角色 | 权限说明 |
|------|----------|
| **管理员 (admin)** | 全部功能，含用户管理 |
| **编辑者 (editor)** | 创建、编辑、删除数据 |
| **查看者 (viewer)** | 仅查看数据，不可修改 |

## 2. 登录与退出

### 2.1 登录系统

1. 打开浏览器访问系统地址（如 `http://服务器IP:端口`）
2. 在登录页输入用户名和密码
3. 点击"登录"按钮

![登录页面示意图：用户名+密码输入框+登录按钮]

| 默认账号 | 密码 | 角色 |
|----------|------|------|
| admin | 123456 | 管理员 |
| editor | 123456 | 编辑者 |
| viewer | 123456 | 查看者 |

> **注意**：首次登录后建议立即修改默认密码。

### 2.2 退出系统

点击页面右上角用户头像/用户名，选择"退出登录"。

## 3. 首页仪表盘

登录后默认进入首页仪表盘，展示以下信息：

- **设备统计卡片**：各类设备总数统计
- **质保状态分布**：在保/即将到期/已过保设备数量
- **按服务商排名**：各建设单位设备数量对比
- **快捷入口**：可快速跳转到各管理页面

---

## 4. 项目管理

### 4.1 查看项目列表

点击左侧菜单"项目管理"，列表展示所有项目信息，包含：
- 项目名称、合同金额
- 建设单位、施工单位
- 验收日期、质保期限、质保到期时间
- 质保状态（在保/即将到期/已过保）

### 4.2 创建项目

1. 点击"新建项目"
2. 填写项目信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| 项目名称 | 唯一标识 | 是 |
| 合同金额 | 精确到两位小数 | 否 |
| 验收日期 | 项目验收的具体日期 | 否 |
| 质保期 | 如"2年"、"3年" | 否 |
| 质保到期时间 | 根据验收日期+质保期计算 | 是 |
| 建设单位 | 项目建设方 | 否 |
| 施工单位 | 项目施工方 | 否 |

3. 点击"保存"

### 4.3 编辑/删除项目

在项目列表页点击对应按钮操作。删除项目前需确保无设备关联。

---

## 5. 路口管理

路口是信号灯和电子警察的容器，先创建项目，再创建路口，最后在路口下添加设备。

### 5.1 查看路口列表

1. 点击左侧菜单"路口管理"
2. 列表展示所有路口，包含：
   - 路口名称、类型
   - 信号灯质保状态、电子警察质保状态
   - 操作按钮（查看、编辑、删除）

### 5.2 创建路口

1. 在路口列表页点击"新建路口"
2. 填写路口信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| 路口名称 | 如"人民路-解放路十字路口" | 是 |
| 路口类型 | 十字路口/丁字路口/行人过街/其他 | 否 |
| 东西走向道路 | 东西方向道路名称 | 否 |
| 南北走向道路 | 南北方向道路名称 | 否 |

3. 点击"保存"

### 5.3 路口详情管理

点击路口列表中的路口名称或"查看"按钮，进入路口详情页。详情页包含三个标签页：

#### 5.3.1 基本信息

可编辑路口基本信息（名称、类型、道路名称）。

#### 5.3.2 信号灯管理

在路口详情页的"信号灯"标签下：

- **添加信号灯**：点击"新增信号灯"
  - 选择所属项目
  - 信号机类型：智能/非智能
  - 填写各设备数量（信号机、箭头灯、满屏灯、行人灯、雷达、诱导屏等）
  - 填写取电说明

- **编辑信号灯**：点击信号灯行后的"编辑"按钮

- **删除信号灯**：点击信号灯行后的"删除"按钮（仅管理员）

- **质保延期**：点击"质保延期"，设置新的质保到期日期

#### 5.3.3 电子警察管理

在路口详情页的"电子警察"标签下：

- **添加电子警察**：点击"新增电子警察"
  - 选择所属项目
  - 抓拍类型：卡口抓拍/综合抓拍等
  - 填写各设备数量（终端服务器、前后拍相机、补光灯、频闪灯、云台摄像机等）
  - 填写网络取电说明

- **编辑/删除/质保延期**：操作方式同信号灯

### 5.4 路口质保延期

可同时延期路口下所有信号灯和电子警察：

1. 在路口详情页点击"质保延期"
2. 选择延期范围：
   - 仅信号灯
   - 仅电子警察
   - 两者同时延期
3. 选择项目，设置新的质保到期日期
4. 点击确认

### 5.5 删除路口

在路口列表页点击"删除"按钮。删除路口时需确保该路口下无关联设备。

## 6. 点位管理

### 6.1 违停抓拍管理

#### 查看列表
点击左侧菜单"违停抓拍"，列表展示所有违停点位及设备信息。

#### 创建违停点位
1. 点击"新建点位"
2. 填写点位名称、抓拍区域、设备类型
3. 保存后在点位详情中添加设备

#### 管理违停设备
进入点位详情页，可添加/编辑/删除设备，设备字段包括：
- 相机抓拍区域、相机数量
- 违停标志数量、监控标志数量
- 取电说明、网络取电说明

### 6.2 卡口管理

操作方式与违停抓拍类似，通过左侧菜单"卡口"进入。

设备字段包括：
- 卡口类型、相机数量
- 频闪灯数量、雷达数量、标志牌数量
- 取电说明、网络取电说明

### 6.3 结构化相机管理

点击左侧菜单"结构化相机"，管理结构化相机设备信息（操作方式同上）。

## 7. 后端设备管理

### 7.1 查看后端设备列表

点击左侧菜单"后端设备"，列表展示所有后端设备信息：
- 设备名称、类型、IP地址
- 服务器/存储/交换机/防火墙/光纤收发器等数量
- 安装位置、取电说明、网络取电说明
- 质保状态

### 7.2 添加后端设备

1. 点击"新增设备"
2. 填写设备信息：
   - 设备名称、类型、所属项目
   - 各类设备数量
   - IP地址、端口、安装位置
   - 取电说明、网络取电说明
3. 保存

### 7.3 编辑/删除后端设备

在列表页点击对应按钮操作。

## 8. 数据统计

点击左侧菜单"数据统计"，进入统计页面。

### 8.1 统计查看

- 按项目统计设备数量
- 按设备类型统计总数
- 质保状态分布统计
- 倒计时统计（距离质保到期的天数）

### 8.2 导出 Excel

1. 在统计页面点击"导出Excel"按钮
2. 系统将生成包含当前统计数据的 Excel 文件并自动下载
3. 导出的文件可用于汇报、归档

---

## 9. 服务排名

点击左侧菜单"服务排名"进入，按设备服役年限从长到短排列，展示全部设备。

### 9.1 排名查看

页面顶部展示三个汇总指标：
- **统计设备数**：当前筛选条件下的设备总数
- **最长服役**：设备中最长的服役年限
- **平均服役**：所有设备的平均服役年限

排名表格展示：排名（金银铜徽章标记前三名）、设备名称、设备类型、验收日期、服役年限。

### 9.2 筛选与搜索

- **按设备类型筛选**：信号灯、电子警察、违停球、卡口、结构化相机、后端设备
- **按设备名称搜索**：支持模糊搜索
- **分页浏览**：支持每页 10/20/50/100 条

### 9.3 数据说明

- 服役年限 = 当前日期 - 项目验收日期
- 数据实时计算，不存储额外数据
- 来源涵盖全部设备类型（信号灯、电子警察、违停球、卡口、结构化相机、后端设备）

## 10. 附件管理

附件功能关联到各个设备实体，用于上传电子档案（合同、验收报告、技术文档等）。

### 10.1 上传附件

1. 进入需要上传附件的实体详情页（如路口详情、项目详情等）
2. 找到"附件"区域
3. 点击"上传文件"
4. 选择本地文件，支持常见文档格式（PDF、Word、Excel、图片等）
5. 可填写文件描述
6. 点击"确认上传"

### 10.2 下载/删除附件

- 在附件列表中点击"下载"按钮下载文件
- 点击"删除"按钮删除附件（需编辑者及以上权限）

## 12. 用户管理（管理员专属）

点击左侧菜单"用户管理"（仅管理员可见）。

### 12.1 查看用户列表

列表展示所有用户信息：用户名、显示名称、角色、状态、最后登录时间。

### 12.2 创建用户

1. 点击"新建用户"
2. 填写用户信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| 用户名 | 唯一标识，不可重复 | 是 |
| 密码 | 建议8位以上 | 是 |
| 显示名称 | 页面右上角显示 | 否 |
| 角色 | admin/editor/viewer | 是 |

3. 点击"保存"

### 12.3 编辑用户

点击用户行的"编辑"按钮，可修改：
- 显示名称
- 角色
- 启用/禁用状态
- 密码（留空则不修改）

### 12.4 删除用户

点击用户行的"删除"按钮即可删除用户账号。

## 13. 常见操作流程

### 13.1 新建项目并关联设备（完整流程）

```
1. 创建项目 → 2. 创建路口/点位 → 3. 添加设备 → 4. 上传附件
```

1. 进入"项目管理"，点击"新建项目"，填写项目信息并保存
2. 进入"路口管理"（或点位管理），新建路口/点位
3. 进入路口/点位详情页，新增设备，选择步骤1创建的项目
4. 在详情页上传相关附件（合同、技术文档等）

### 13.2 设备质保延期流程

```
1. 找到设备所在详情页 → 2. 点击"质保延期" → 3. 设置新到期日
```

- 可在路口/点位详情页对单个设备延期
- 也可在路口详情页一次性延期所有设备
- 延期记录会自动保存，新到期日覆盖原到期日

### 13.3 导出数据报表

```
1. 进入"数据统计" → 2. 查看统计结果 → 3. 点击"导出Excel"
```

## 14. 注意事项

1. **密码安全**：首次登录后请立即修改默认密码
2. **权限控制**：viewer 角色只能查看，无法修改任何数据
3. **数据删除**：删除项目或路口前，请确认无关联设备
4. **质保日期**：设备质保到期日期由项目验收日期+质保期自动计算，手动延期后以延期日期为准
5. **文件上传**：请勿上传敏感或超大文件，单个文件建议不超过 50MB
6. **浏览器兼容**：推荐使用 Chrome、Edge 最新版本
